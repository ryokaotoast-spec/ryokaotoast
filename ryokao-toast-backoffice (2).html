วันที่จำนวนออเดอร์ยอดขายกำไรโดยประมาณ

แก้ราคาขาย ต้นทุนวัตถุดิบ และต้นทุนบรรจุภัณฑ์ได้โดยตรง ระบบจะคำนวณกำไร/ชิ้นให้อัตโนมัติ

รูปภาพเมนูหมวดสต็อกวันนี้ราคาขายต้นทุนวัตถุดิบบรรจุภัณฑ์ต้นทุนรวมกำไร/ชิ้น% กำไร

ตารางอ้างอิงต้นทุนวัตถุดิบ ไว้เทียบตอนคำนวณต้นทุนต่อเมนู (แก้ราคาซื้อได้เมื่อของขึ้นราคา)

วัตถุดิบราคาซื้อ (บาท)ปริมาณที่ซื้อหน่วยใช้ต่อชิ้นต้นทุน/ชิ้น

แนบสลิปขึ้น Google Drive อัตโนมัติ (แยกโฟลเดอร์ตามเดือน)

ต้องสร้าง Google OAuth Client ID จาก Google Cloud Console (เปิดใช้งาน Drive API และเพิ่มโดเมนที่ใช้งานจริงใน Authorized JavaScript origins) แล้วนำมาใส่ที่นี่ ระบบจะสร้างโฟลเดอร์ "Ryokao Toast - สลิปลูกค้า" และโฟลเดอร์ย่อยตามเดือนให้อัตโนมัติ
